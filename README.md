# 📱 Tugas Praktikum PAM Week 3

Aplikasi profil diri sederhana yang dibangun menggunakan **Jetpack Compose** sebagai bagian dari tugas praktikum Pengembangan Aplikasi Mobile.

---

## 📝 Deskripsi Tugas
Membangun aplikasi Android dengan fitur:

- **Halaman Profil**
  - Header dengan foto profil (berbentuk lingkaran) dan nama
  - Bio / deskripsi singkat
  - Informasi kontak:
    - Email
    - Phone
    - Location

- **Reusable Composable Functions (minimal 3)**
  - `ProfileHeader`
  - `ProfileCard`
  - `InfoItem`

- **Penggunaan Komponen Dasar**
  - Layout: `Column`, `Row`, `Box`
  - UI: `Card`, `Text`, `Button`, `Image`, `Icon`

- **Bonus**
  - Animasi menggunakan `AnimatedVisibility`

---

## 🚀 Fitur & Implementasi

- **ProfileHeader**
  - Menampilkan foto profil berbentuk lingkaran
  - Menggunakan `clip(CircleShape)` dan `border`

- **ProfileCard**
  - Kartu informasi profil
  - Muncul dan menghilang dengan animasi fade (`AnimatedVisibility`)

- **InfoItem**
  - Komponen reusable untuk menampilkan data kontak
  - Digunakan untuk Email, Phone, dan Location

- **Interaktivitas**
  - Tombol **"Show Details"** untuk menampilkan/menyembunyikan detail profil

---

## 🛠️ Tech Stack & Komponen

- **Jetpack Compose**
- **Material Design 3**

**Layouts:**
- `Column`
- `Row`
- `Box`

**UI Components:**
- `Text`
- `Button`
- `Image`
- `Icon`
- `Card`

**Animation:**
- `AnimatedVisibility` (Fade In / Fade Out)
